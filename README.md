# SportHive

A modern Sports Event Management Platform.

## Project Structure

```
SportHive/
├── frontend/          # Next.js frontend application
├── backend/           # Express.js backend API
└── README.md
```

## Technology Stack

### Frontend
- Next.js (Latest App Router)
- React
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod Validation
- Axios
- Framer Motion
- Recharts / Chart.js

### Backend
- Node.js
- Express.js
- TypeScript
- MongoDB
- JWT Authentication
- bcrypt
- Cookie Parser
- CORS
- dotenv

### Database
- MongoDB ONLY

## Development Rules

1. Never mix backend and frontend
2. Maintain clean architecture
3. Build one feature at a time
4. Test before moving to next feature
5. Commit after every completed feature
6. Push after every commit
7. Always ask before continuing to next phase

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- MongoDB instance

### Installation

#### Frontend
```bash
cd frontend
npm install
npm run dev
```

#### Backend
```bash
cd backend
npm install
npm run dev
```

## Environment Variables

Never create .env without asking. When environment variables are required, STOP and ask.
